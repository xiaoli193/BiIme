# 中英对照拼音输入法（BiIme）

一个 Android 输入法（IME）：**和普通拼音输入法一样打字，唯一的区别是——输入拼音时，候选栏里每个中文候选的下方都会显示它对应的英文释义。**



> 📄 **两份配套文档**
> * [`FILES.md`](FILES.md) —— 每个文件干什么、数据怎么流动、想改 X 动哪个文件
> * [`PACKS.md`](PACKS.md) —— 扩展包开发指南（字段表、五类能力、校验、完整例子）

## 功能

| 操作 | 效果 |
| --- | --- |
| 点候选 | 上屏中文（可切简/繁） |
| **长按候选** | 直接上屏该候选对应的英文 |
| 候选栏右侧「中 / EN」 | **一键切换**：切到 EN 后，点候选直接出英文 |
| 候选栏右侧「简 / 繁」 | 切换上屏字形 |
| 空格 | 有拼音时上屏首选词，没有时插入空格 |
| ⌫ | 长按连续删除 |
| 「符 / ABC」 | 数字符号页 |
| 末尾 `abc` 候选 | 原样上屏（打英文、或拼音查不到时的兜底） |

* 完全离线，不联网、不申请任何权限、不收集输入内容。
* 词典：CC-CEDICT（CC BY-SA 4.0）；词频：jieba dict（MIT）。二者在构建时被编译成一个紧凑的二进制资源打进 APK。

## 安装与启用

手机安装，然后：

1. 打开应用「中英对照拼音输入法」→ 点「① 去系统设置启用本输入法」，在列表里勾选它；
2. 回到应用点「② 切换到本输入法」，或在任意输入框里长按空格/点键盘角标切换到它；
3. 在应用的**试打演示**里点字母打 `nihao`、`woaini`、`beijing`，就能看到中文候选 + 英文释义；
   点候选上屏中文、长按候选上屏英文。

> Android 13+ 的「设置 → 系统 → 语言和输入法 → 屏幕键盘」里也能切换。

## 从源码构建

不需要 Gradle / Android Studio，只需要 JDK 17 + Android SDK（build-tools 34、platform android-34）：

```bash
export ANDROID_SDK_ROOT=/opt/android-sdk
# 1. 生成词典资源（需要 CC-CEDICT 与 jieba 词频表）
python3 tools/build_dict.py \
    --cedict /root/dict/cedict.txt \
    --freq   /root/dict/jieba_dict.txt \
    --out    app/assets/pinyin.dict
# 2. 构建
bash build.sh
# 产物：dist/BiIme-1.0.apk
```

数据源：

* CC-CEDICT：<https://www.mdbg.net/chinese/dictionary?page=cedict>
* jieba 词频表：<https://github.com/fxsjy/jieba>

```

```

`Settings.Secure.ENABLED_INPUT_METHODS`、`DEFAULT_INPUT_METHOD` 从 Android 14 起

  抛异常则退回"输入法每次弹出时写的时间戳心跳"（`Packs.markImeActive`）。

### 词典格式

`app/assets/pinyin.dict` 每行 7 个制表符分隔字段，整表按第 1 列字典序排序：

```
key \t 简体 \t 繁体 \t 带声调拼音 \t 英文释义 \t 音节数 \t 词频分
nihao   你好    你好    ni3 hao3      hello; hi      2       1999275
```

`key` 是无声调小写拼音（`ü` 写作 `v`）。运行时整个文件以 UTF-8 字节数组常驻内存，用 `int` 偏移索引行并二分查找，避免十万级 String 对象；`词频分` 来自 jieba 词频，越小越常用，精确匹配优先于前缀匹配。

### 整句兜底切分

词典里查不到整词时（`woaini`、`xiexienin`、`woshiyigexuesheng`），候选栏会补一条整句切分结果：

1. 先用「最长匹配」定出合法音节边界，只在音节边界上组词——避免 `qian` 被切成 `qi+an`（其按）；
2. 再在边界上做 DP，打分 = `Σ log(字频)` + 成词奖励 − 切分惩罚，取最优切分；
3. 中文取切分结果，英文用各段释义拼起来（`woaini` → 我爱你 / `I + to love + you`）。

实测：`woaini → 我爱你`、`nihaoma → 你好吗`、`xiexienin → 谢谢您`、`woxihuanni → 我喜欢你`、`woshiyigexuesheng → 我是一个学生`。

## 已知限制

* 没有语言模型，长串连打时个别字会选到同音的高频字（`duoshaoqian → 多少前` 而不是 多少钱）；
  分开打 `duo shao qian` 或用候选栏逐段上屏都能得到正确结果。
* CC-CEDICT 没有的常用短语靠上面的兜底切分补，释义是逐段拼的，不如词典释义精确。
* 只在 arm64 真机 / 模拟器上做过静态验证（词典逻辑用 JVM 跑过全量用例），UI 没在设备上实机跑过。

## 联想搜索与拼音校正

### 联想搜索

上屏一个中文词之后，候选栏接着给出**以它开头的常用词**，点一下就上屏，并且可以继续联想（链式）：

```
打 nihao → 点「你好」上屏
候选栏接着给出： 你好吗 / 你好帅 …（按词典里以「你好」开头的词）
```

数据来自构建期生成的 `app/assets/assoc.idx`（6 万条按中文排序的词表，2 MB）：
`tools/build_dict.py` 从 CC-CEDICT 里挑出 2–4 字、且 jieba 收录过词频的词条，
按中文排序写出来；运行时二分查找「以某词开头」的区间，按词频排序。
它自己不联想自己，最多给 12 条。

* 打字时联想自动收起；退格清空输入后也会收起。
* 上屏英文、标点、字母不会触发联想（只认中文尾巴）。
* 想关掉：内置包「关闭联想」，或在扩展包里写 `"func": {"associate": false}`。

### 拼音校正

两层，**都不影响正常输入**（精确命中永远排在前面）：

| 层 | 覆盖 | 例子 |
| --- | --- | --- |
| 模糊音 | zh↔z、ch↔c、sh↔s、n↔l、f↔h、ang↔an、eng↔en、ing↔in、ong↔on、iang↔ian、uang↔uan | `zongguo → 中国(≈zhongguo)`、`sihou → 时候(≈shihou)`、`beijin → 北京`、`lanhai → 南海(≈nanhai)` |
| 拼错纠正 | 相邻字母颠倒、漏字母、按错键（键盘左右相邻） | `nihso → 你好(≈nihao)` |

* 模糊音**始终参与**，但结果带 20000 的惩罚分，也就是「纠正来的词要明显更常用才能排到前面」——
  所以 `sihou` 第一是「时候」而不是同样精确命中的「嗣后」。
* 拼错纠正只在**精确命中为空**时才试（结果带 60000 惩罚分），不会往正常输入里塞噪音。
* 纠正生效时，候选栏最左边会出现一个小灰字 `≈shihou`，告诉你实际按哪个拼音命中的。
* 单字母规则（n/l、f/h）只在词首替换，避免 `an → al` 这种荒唐搜索。
* 想关掉：内置包「严格拼音」，或写 `"func": {"fuzzyPinyin": false, "typoCorrect": false}`。

### 性能

* 联想索引 6 万条加载 **21 ms**，主词典 11 万条 **94 ms**，都在后台线程做。
* 一次按键的搜索：精确 1 次 + 模糊音最多 14 次二分查找，实测 1 ms 以内；
  拼错纠正最多 48 次，且只在精确命中为空时触发。

### 键盘布局

```
┌──────────────────────────────────────────────┐
│ 你好      拟好      你      abc  │ 中 简 ⌄ │  ← 候选 + 控制键同一行 50dp
│ hello;hi  …         …            │ 29dp 三个 │
├──────────────────────────────────────────────┤
│ q w e r t y u i o p                          │  ← 每行 44dp
│  a s d f g h j k l                           │
│   ⇧  z x c v b n m  ⌫                        │
│ 符   ，     [  空格  ]      。     换行       │
├──────────────────────────────────────────────┤
│ 、 。 ， ？ ！ ： ； “ ” …                    │  ← 符号页与字母页同形：
│  ‘ ’ （ ） 《 》 【 】 —                      │     10 / 9 / 7 三行 26 格
│    ·  ～  〈  〉  「  」  『        ⌫          │
│ #+=  ，     [  空格  ]      。     换行       │
└──────────────────────────────────────────────┘
```

* **候选栏右侧三个控制键**：`中`/`EN`（切换点候选上屏中文还是英文）、`简`/`繁`、
  `⌄`（收起键盘）。每个约 29 dp 宽、10.5sp 字，尽量不占候选的位置。
* **符号页做成和 26 键一样的排布**：第一行 10 格、第二行 `0.5 + 9 + 0.5`、
  第三行 `1.5 + 7 + 删除`，和字母页完全对齐。
  换页时键宽、键高、键盘总高都不会跳（每页都是 3 行符号 + 1 行底栏）。
* 内置三页符号各 26 格：
  * 标点页 `、。，？！：；""…‘’（）《》【】—·～〈〉「」『`
  * 数字页 `1234567890 @#￥%&*-+( )=/\_~^`
  * 更多页 `×÷≈±°§¥€£© ®™№‰µΩ℃㎡㎏ √∞π∑∫≠≤`
* 扩展包的 `punct.page1/2/3` 现在最多可以给 **26 格**；给不满的用等宽空位补齐，
  所以不会出现「只给了 5 个符号、键被拉得很宽」的情况。
* 按键说明只在空闲时显示一行小字：「输入拼音，候选下面的小字就是英文」。

高度：候选栏 50 dp + 4 × 44 dp = **226 dp**（改造前是 40 + 60 + 4×46 = 284 dp）。
想再调高矮用「键盘样式」扩展包（`keys.rowHeight` / `keys.keyFont` / `keys.keyRadius`）。
